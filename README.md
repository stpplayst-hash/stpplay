# STP PLAY - Official Repository

STP PLAY is a premium media player designed for Smart TVs and Smartphones, offering high performance and a cinematic experience for Xtream API and M3U playlists.

## 🚀 Main Features

- **Premium Smart TV Experience**: Fluid navigation optimized for remote controls with a modern "frosted glass" interface.
- **Dynamic Highlights**: Intelligent auto-rotating carousel for new releases.
- **Multi-Profile System**: Separate profiles for the whole family, including a secure **Kids Profile** with automatic keyword filtering.
- **Smart "Continue Watching"**: Automatically tracks your progress in movies and series.
- **Live TV with EPG**: Full Electronic Program Guide with reminders.
- **Ultra-Fast Loading**: Powered by Paging 3 technology to handle 50,000+ items smoothly.
- **Multilingual**: Native support for Portuguese, English, and Spanish.

## 📥 Installation

### Android TV / Fire Stick (via Downloader App)
1. Open the **Downloader** app on your TV.
2. Enter the official shortcode or direct URL provided by your provider.
3. Download and install the APK.

### Manual Installation
1. Go to the GitHub Releases page.
2. Download the latest `STP-PLAY-v1.2.apk`.
3. Open the file on your device and follow the installation instructions.
